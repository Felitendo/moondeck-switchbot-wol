# Changelog

## v1.0.0

_2026-10-09_

Welcome to moondeck-switchbot-wol `v1.0.0`! The first release, and a rewrite. One command does it all now, with a menu in the terminal on both ends.

### 🚨 Breaking changes

- Everything is set up again from scratch. On the PC run `moondeck-switchbot-wol host` and make a new pairing code, then paste it on the Deck.

### Highlights

- A menu on the Deck and on the PC
- Sets up MoonDeck for you, and puts it back
- Wakes only once, so the PC never turns off again
- Works with SDDM too
- English and German
